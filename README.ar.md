# ⚒ Forge

> **ابنِ مرة واحدة. وقّع في أي مكان.**

### محرك بناء مفتوح المصدر لمشاريع iOS.

<a href="README.md">🇬🇧 EN</a> · <a href="README.ar.md">🇸🇦 AR</a>

</div>

---

Forge هو محرك أتمتة مفتوح المصدر مصمم لبناء مشاريع iOS المدعومة من مستودعات GitHub وإنتاج ملف IPA غير موقّع، جاهز للتوقيع باستخدام الأداة التي تختارها.

لا تحتاج إلى إعداد Xcode محليًا.

لا يحتاج Forge إلى حساب Apple Developer.

لا تحتاج إلى شهادات توقيع أو Provisioning Profiles ضمن مسار البناء الأساسي.

فقط أدخل مستودع GitHub، ودع Forge يتولى عملية البناء.

---

## ✨ لماذا Forge؟

بناء مشاريع iOS خارج Xcode قد يكون معقدًا.

كل مشروع يمكن أن يختلف في:

- هيكل المشروع
- Workspaces
- Schemes
- Dependencies
- إعدادات البناء

Forge مصمم لإزالة أكبر قدر ممكن من هذا العمل اليدوي.

مهمته بسيطة:

> **حلّل. اكتشف. ابنِ. صدّر.**

أما التوقيع فهو اختيارك.

## 🚀 المميزات

- 📥 استنساخ مستودعات GitHub
- 🔍 اكتشاف Xcode Projects وWorkspaces تلقائيًا
- 🧠 اكتشاف Schemes المتاحة تلقائيًا
- ⚙️ تجهيز بيئة البناء
- 📦 بناء مشاريع iOS باستخدام أدوات Xcode من سطر الأوامر
- 🗂 إنشاء Xcode Archives
- 📤 إنشاء IPA غير موقّع
- ☁️ رفع IPA غير الموقّع كـ GitHub Actions Artifact
- 🧩 تصميم قابل للتوسع لدعم Plugins مستقبلًا
- 🛠 أتمتة تعتمد على GitHub Actions

## 🎯 فلسفة Forge

يفصل Forge بشكل متعمد بين **البناء** و**التوقيع**.

مسؤولية Forge هي تجهيز التطبيق وبناءه.

أما عملية التوقيع فتبقى خارج المسار الأساسي لـ Forge.

وهذا يسمح للمطور باستخدام أداة التوقيع التي تناسب طريقة عمله.

**Forge يبني. وأنت تختار طريقة التوقيع.**

## ⚡ البدء السريع

يعمل Forge حاليًا من خلال GitHub Actions.

### 1. افتح Actions

افتح تبويب **Actions** داخل مستودع Forge.

### 2. اختر Forge

اختر Workflow:

**Forge**

### 3. تشغيل Workflow

اضغط **Run workflow**.

### 4. أدخل المستودع

أدخل مستودع GitHub بهذا الشكل:

`owner/repository`

مثال:

`iRaay/Navi`

### 5. شغّل Forge

سيقوم Forge بـ:

- استنساخ المستودع
- تحليل المشروع
- اكتشاف Xcode Project أو Workspace
- اكتشاف الـ Schemes
- تجهيز البيئة
- بناء مشروع iOS
- إنشاء Xcode Archive
- إنشاء IPA غير موقّع

### 6. تحميل النتيجة

بعد انتهاء Workflow، افتح الـ Artifacts.

ستجد:

`Forge-unsigned-ipa`

ويحتوي على:

`Forge-unsigned.ipa`

يمكن بعد ذلك توقيع ملف IPA باستخدام أداة التوقيع التي تختارها.

---

## 📱 التوقيع

التوقيع موجود عمدًا خارج المسار الأساسي لـ Forge.

يمكن تمرير ملف IPA غير الموقّع إلى أدوات متوافقة مثل:

- Feather
- AltStore
- Esign
- Sideloadly
- وغيرها من أدوات التوقيع المتوافقة

لا يحتاج Forge إلى شهادة توقيع أو Provisioning Profile لإنشاء ملف IPA غير موقّع.

## 🏗 بنية المشروع

بنية Forge الأساسية:

- `.github/workflows/` — GitHub Actions Workflows
- `scripts/analyze.sh` — تحليل المشروع
- `scripts/prepare.sh` — تجهيز البيئة
- `scripts/build.sh` — بناء وأرشفة مشروع iOS
- `scripts/export.sh` — تصدير IPA غير موقّع
- `templates/` — قوالب البناء المستقبلية
- `plugins/` — نظام الإضافات المستقبلي
- `docs/` — توثيق المشروع

يعتمد المسار الأساسي على مبدأ بسيط:

**Analyze → Prepare → Build → Export**

كل مرحلة لها مسؤولية محددة.

## ⚠️ القيود الحالية

Forge v0.1.0 هو إصدار مستقر مبكر.

يركز الإصدار الحالي على المشاريع التي يمكن تحليلها وبناؤها بنجاح باستخدام أدوات Xcode من سطر الأوامر.

قد تحتاج بعض المشاريع إلى إعدادات إضافية أو Dependencies أو Build Settings لا يتم التعامل معها تلقائيًا بعد.

سيستمر تطوير اكتشاف المشاريع والـ Schemes وتحسينه في الإصدارات القادمة.

## 🌍 الرؤية

يهدف Forge إلى أن يصبح محرك بناء محمولًا وقابلًا للتوسع لمشاريع iOS.

الهدف طويل المدى بسيط:

> **أعطِ Forge مستودع GitHub واحصل على Build جاهز للتوقيع بدون فتح Xcode.**
